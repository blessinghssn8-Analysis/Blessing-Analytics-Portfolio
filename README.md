# Blessing Oluwaseyi — Analytics Portfolio

A responsive, accessible, dark-themed static portfolio built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` from this directory and visit http://localhost:8000.

## Publish on GitHub Pages

1. Create a public GitHub repository (for example `analytics-portfolio`).
2. Upload all files, preserving the folder structure.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch.
4. Choose `main` and `/ (root)`; save.
5. Your website will be at `https://YOUR_USERNAME.github.io/analytics-portfolio/` (adjust for your repository name).

## Before launch

- Verify all case-study results against source notebooks and data.
- Replace project link placeholders with real notebooks, SQL scripts and dashboards.
- Add verified degree, certification, employment dates and outcome metrics.
- Add a real one-page resume PDF and replace the resume request link with a download link.
- If desired, convert `assets/social-preview.svg` to a 1200×630 PNG and update `og:image` to an absolute deployed URL for wider social preview compatibility.
- Add a canonical URL and `og:url` after the final site URL is known.
- Test mobile navigation, contrast, keyboard focus, and all external links.

## Privacy

Do not publish employer customer data, private sales records, or academic datasets without permission.
